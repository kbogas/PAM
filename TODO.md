## P1 · Build embeddings

- [x] **~~07. Implement the sparse Bag of Paths transformer.~~** The current `generate_path_features` returns one cell value per pair per hop and materializes all ordered pairs by default. Retain that operation for existing callers. Build BoP in a separate module, using the authors’ experiment code as the reference. One requested object is one document. Namespace tokens by hop and role. Count incoming/outgoing features separately for nodes, support both directions and endpoint features for pairs, and pool occupied cells for whole graphs. For induced subgraphs, recompute walks inside the selected subgraph so paths cannot leave and re-enter it. Define lossy cell tokens now and reserve an explicit interface for exact ordered-path tokens from item 10. [BoP experiments](https://github.com/kbogas/PAM_BoP)

  Proposed entry points are `BagOfPaths(level=...).fit(X)`, `transform(X)`, `fit_transform(X)` and `get_feature_names_out()`. A batch identifies the graph, its ordered hop matrices and the requested objects. Add thin one-shot helpers `bop.generate_node_embeddings(pams, nodes)`, `generate_edge_embeddings(pams, pairs)`, `generate_subgraph_embeddings(graph, node_sets)` and `generate_graph_embeddings(graph_pams)`. The last takes one hop-matrix collection per graph. Accept graph-qualified selections for multi-graph batches. Document shared-map requirements for precomputed matrices.

  **Done when** one row corresponds to each requested object in order, including duplicates and isolates. Different local node IDs and overlapping relation subsets yield aligned columns. Fitting learns vocabulary and IDF only on the training objects. Transform reuses both and handles unseen tokens, empty selections and incompatible mappings predictably. Compare counts and TF–IDF by hand and test sklearn cloning and pipeline use. Expose hop cutoff, count/TF–IDF weighting, frequency cutoffs, feature cap, normalization and optional neighbor aggregation. Provide task presets with provenance. For example, Appendix C.1 uses `min_df=2`, `max_df=0.99` and a 10,000-feature cap, with dataset-specific hop and self-weight choices. Provide defaults that also work on tiny collections. [Paper, §2.6 and Appendix C](https://arxiv.org/html/2411.11149v1)

  Completed on 25 November 2026. Added `prime_adj.bop` with sklearn-compatible `BagOfPaths` and graph-qualified `BoPDocument` inputs. Sparse lossy tokens are namespaced by hop and incoming/outgoing, pair direction, endpoint or graph role; structurally stored zeros are preserved. Fit learns count/TF–IDF vocabulary and IDF only from training documents, while transform reuses columns, ignores unseen tokens and returns stable empty shapes. Shared mapping signatures guard multi-graph alignment without including graph/local IDs in tokens. One-shot node, pair, graph and induced-subgraph helpers preserve request order and duplicates; induced graphs recompute PAMs after filtering. Parameters cover hop cutoff, weighting, frequency cutoffs, cap, normalization, endpoint/direction features and neighbor aggregation/self weight. Tiny and Appendix C.1 presets are recorded in code and `docs/bag-of-paths.md`. Hand-checked counts/IDF, isolates, cloning, incompatibility, helpers and leave/re-enter exclusion pass; the full suite has 36 passing tests and both distributions build.

- [ ] **11. Build a rule book with ordered evidence.** Reuse the same-cell overlap in `create_ruleset`. The reversed sequence has the same scalar product. Keep ambiguous lossy values identifiable. Define support as distinct endpoint pairs, document confidence smoothing and head-coverage denominators, and expose ordered bodies, head labels, counts and optional witnesses in a stable table. **Done when** hand-counted rules agree on support and coverage, including reversed paths, multiple direct labels, log mode, identity rules and empty output.

Start with an exact CPU implementation that interns only observed ordered extensions and accumulates integer multiplicities per occupied cell. Expose hop-specific lookup tables and explicit resource limits. Compare decoded results against the paper’s recurrence and the independent enumerator before selecting a compiled optimization. **Done when** every occupied cell round-trips at multiple hops, including repeated walks and opposite orderings, and the exact mode has zero collisions in item 09.
