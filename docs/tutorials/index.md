# Tutorials

Each tutorial has a matching executable under `examples/` and is run by CI.

- [Node embeddings](nodes.md): incoming and outgoing path features.
- [Pair embeddings](pairs.md): both directions plus endpoint context.
- [Induced subgraphs](subgraphs.md): recompute walks inside each selection.
- [Multiple graphs](multigraph.md): align columns with one shared relation map.
- [WN18RR walkthrough](wn18rr.md): real relation-prediction dataset, splits,
  dimensions, and ranking metrics.
