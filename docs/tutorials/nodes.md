# Node embeddings

One requested node produces one row. Incoming and outgoing cell values are
separate, hop-qualified tokens. Request order and duplicates are preserved.

```bash
python examples/tutorial_nodes.py
```

Expected output: `(3, 6) 12`.

See the complete source in
[`examples/tutorial_nodes.py`](https://github.com/kbogas/PAM/blob/main/examples/tutorial_nodes.py).
