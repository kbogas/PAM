# Prime Adjacency Matrices and Bag of Paths

This is the versioned documentation for `prime-adj` 0.0.11.

Prime Adjacency Matrices encode multi-relational directed graphs in sparse
numeric matrices. Bag of Paths converts their occupied multi-hop cells into
features for nodes, pairs, induced subgraphs, and whole graphs.

Start with [installation and migration](installation.md), then choose a
[tutorial](tutorials/index.md). The [mapping contract](mapping-contract.md)
states the supported numerical semantics and exactness limits.

```bash
python -m pip install "prime-adj[bop]"
```

The project supports Python 3.11–3.14 on Linux and macOS.
